# 마케팅 SQL 앱

B2C 커머스 마케팅 데이터(가입 · 광고비 · 첫 구매 · 재구매 · 매출)를 한국어로 물어보고, 브라우저 안의 DuckDB로 계산해 답을 보여 주는 앱입니다. `data/`의 CSV는 수업용 가상 데이터입니다.

## 쓰기 전에

1. 이 앱은 데이터를 브라우저 안에서 읽는다. 올린 파일은 서버에 저장되지 않는다.
2. AI에는 질문 · 테이블 설명 · 집계 결과(최대 50행)만 간다. 원본 행은 가지 않는다.
3. AI가 쓴 SQL은 실행 전에 읽어 보고, 결과 숫자 하나는 직접 검산한다.
4. 올린 파일의 «읽은 행 수»와 «올라간 행 수»가 다르면(✕) 그 결과를 믿지 않는다.
5. 파일 이름이 같으면 나중에 올린 파일이 앞의 것을 대신한다.

1번과 2번을 조금 더 풀어 쓰면 다음과 같습니다.

- 올린 파일은 브라우저 메모리에만 있고, 새로고침하면 사라집니다. 이때 `data/`의 기본 파일로 돌아갑니다.
- AI에 가는 것은 질문, 테이블 설명(`schema.json`), 올린 테이블의 이름 · 컬럼 이름 · 타입 · 행 수, AI가 쓴 SQL, 집계 결과(최대 50행)입니다. 고객 · 주문 번호가 든 결과나 집계가 아닌 결과는 행을 빼고 보냅니다.

## 내 PC에서 실행

프로젝트 폴더에 `.env` 파일을 만들고 키를 넣습니다. 이 파일은 올라가지 않습니다(`.gitignore`와 `.vercelignore`에 들어 있습니다).

```
GEMINI_API_KEY=여기에_키
GEMINI_MODEL=
```

`GEMINI_MODEL`을 비워 두면 `gemini-3.5-flash-lite`를 씁니다. 그다음 실행합니다.

```
python tools/serve.py
```

브라우저에서 http://127.0.0.1:8780 을 엽니다. 화면과 `/api`가 함께 뜹니다. 설치할 것은 없습니다(Python 표준 라이브러리만 씁니다).

## Vercel에 배포

- 정적 파일(`index.html` · `app/` · `data/` · `presets/`)과 `api/`의 Python 함수를 그대로 올립니다. 빌드 단계는 없습니다.
- 프로젝트 설정의 Environment Variables에 `GEMINI_API_KEY`를 넣습니다. 모델을 바꾸려면 `GEMINI_MODEL`도 넣습니다.
- `.vercelignore`가 `.env` · `tools/` · `tests/` · `다음달/` · `.vscode/`를 올리지 않게 막습니다.
- `api/`에는 함수 파일(`sql.py` · `why.py`)만 둡니다. Vercel은 `api/` 안의 `.py` 파일을 전부 함수로 보기 때문입니다. 공통 코드는 `lib/`에 있고, 각 함수 파일은 `class handler(BaseHTTPRequestHandler)`를 소스에 직접 적어야 합니다.
- Python 함수에는 프로젝트의 파일이 기본으로 함께 들어가므로, 함수가 읽는 `schema.json`을 따로 지정하지 않아도 됩니다.
- `vercel.json`은 함수의 최대 실행 시간(60초)만 정합니다.
- 배포 주소에서는 `schema.json`도 누구나 볼 수 있습니다. 테이블 설명뿐이고 데이터는 들어 있지 않습니다.
