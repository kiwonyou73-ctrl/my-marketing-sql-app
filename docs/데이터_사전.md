# 데이터 사전 — 마케팅 (B2C 커머스 플랫폼 · 가입 · 광고비 · 쿠폰 · 주문)

> 이 데이터는 수업용으로 만든 **합성 데이터**입니다. 실제 회사 · 실제 사람과 관계가 없습니다.

## 어떤 회사의 데이터인가

뷰티 · 패션 · 식품 · 건강 · 생활 · 디지털 상품을 파는 소비자 대상 모바일 커머스 플랫폼입니다. 마케팅팀은 채널(검색광고 · 인스타그램 · 유튜브 · 인플루언서 · 친구초대)별 캠페인에 광고비를 쓰고, 가입자가 첫 구매를 하고 다시 사는지를 월간으로 보고합니다.

- 기간: **2024-07-01 ~ 2025-12-31** (18개월). `users`에는 기간 이전에 가입한 기존 고객도 들어 있습니다.
- `다음달/` 폴더에는 2026-01까지 늘어난 같은 이름의 파일 세 개(`users` · `orders` · `ad_spend_daily`)가 있습니다.

## 테이블 한눈에

| 테이블 (파일) | 한 행 = | 행 수 | 키 |
|---|---|---:|---|
| `campaigns` | 광고 캠페인 1개 | 34 | campaign_id |
| `ad_spend_daily` | 캠페인 1개의 하루 광고 집행 | 2,598 | campaign_id + spend_date |
| `users` | 고객(가입자) 1명 | 57,792 | user_id |
| `coupons` | 쿠폰 종류 1개 | 2 | coupon_id |
| `orders` | 주문 1건 | 123,763 | order_id |

관계: `campaigns` 1 : N `ad_spend_daily` (`campaign_id`) / `campaigns` 1 : N `users` (`signup_campaign_id`, 광고로 가입한 고객만) / `users` 1 : 0~N `orders` (`user_id`). 가입만 하고 한 번도 사지 않은 고객이 있습니다 / `orders.coupon_id` → `coupons.coupon_id`

## 컬럼

### campaigns

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| campaign_id | 문자 | 캠페인 번호 |
| channel | 문자 | 채널 (검색광고 · 인스타그램 · 유튜브 · 인플루언서 · 친구초대) |
| campaign_name | 문자 | 캠페인 이름 |
| start_date | 날짜 | 시작일 |
| end_date | 날짜 | 종료일 |
| budget | 정수 | 예산(원). 실제 광고비보다 약간 큽니다 |

### ad_spend_daily

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| campaign_id | 문자 | 캠페인 번호 |
| spend_date | 날짜 | 집행일 |
| spend | 정수 | 광고비(원) |
| impressions | 정수 | 노출 수 |
| clicks | 정수 | 클릭 수 |

### users

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| user_id | 문자 | 고객 번호 |
| signup_date | 날짜 | 가입일 |
| signup_channel | 문자 | 가입 채널. 광고 채널 다섯 + 자연유입 |
| signup_campaign_id | 문자 | 가입으로 이어진 캠페인. 광고로 가입하지 않았으면 **결측값** |

### coupons

|---|---|---|

| coupon_type | 문자 | 쿠폰 유형 |
| discount_amount | 정수 | 할인액(원) |

### orders

| 컬럼 | 타입 | 뜻 |
|---|---|---|
| order_id | 문자 | 주문 번호 |

## 지표 정의 — 이 회사의 기준

| 지표 | 정의 |
|---|---|
| 가입자 | `users`의 고객 수 (가입일 기준) |
| 첫 구매 고객 | `orders`에 한 번이라도 나오는 고객. 가입자 중 주문이 없는 고객은 아직 첫 구매 전입니다 |
| 구매 전환율 | 첫 구매 고객 ÷ 가입자 |
| CAC | 채널의 광고비 합 ÷ 그 채널 캠페인으로 가입해 첫 구매한 고객 수. **광고비를 고객 테이블과 바로 조인하면 광고비가 고객 수만큼 반복됩니다** |
| 재구매율(30일) | 첫 구매일 다음 날부터 30일 안에 주문이 한 번 더 있는 고객 비율 |
| 매출 | `orders.amount`의 합 |

## 회사 규칙 (숫자를 읽을 때 알아야 하는 것)

- 신규가입 쿠폰(CPN-NEW)은 가입 후 첫 구매에만 쓸 수 있는 5,000원 할인입니다. 2025-09부터 가입자 대부분에게 발행했습니다.
- 광고를 보지 않고 들어온 고객은 `signup_campaign_id`가 비어 있고 `signup_channel`이 «자연유입»입니다.
- 가입일과 첫 구매일은 보통 0~14일 차이입니다.
